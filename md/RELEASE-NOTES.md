# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 时间轴

- 新增 `StartsUsing` 时间轴同步，使用稳定的 Framework 读条轮询，不重新启用旧 Cast Hook。
- 改进时间轴 parser，支持 `forcejump`、`source: [...]`、单引号/反引号 id 与 param1。
- 修复旧用户索引可能遮挡内置索引，导致部分副本提示“当前区域没有时间轴”的问题。
- 新增硬编码源码时间轴路径 `E:\git\DalamudACT\DalamudACT\Features\Timeline\Data`，用于本地开发环境优先加载。
- 时间轴设置顶部新增在线时间轴操作入口，并新增“已有时间轴”窗口查看当前可发现时间轴列表。
- 新增网络包增强诊断模式，用于排查时间轴同步相关原始包。

### 战斗流水

- 承伤流水新增 HP 与减伤快照，显示目标减伤/护盾和来源减伤 debuff。
- 补充多职业减伤/护盾 StatusId，覆盖坦克、四奶、远敏、法系、近战关键减伤。
- 重设计战斗流水筛选：按角色 + 输出/承伤/治疗/死亡/减伤分析等内容多选过滤。
- 新增全文搜索，可按技能名、状态名或任意流水文本过滤。
- 无减伤承伤会高亮显示，便于排查减伤覆盖。
- 新增场地特效记录开关，并可在战斗流水筛选中显示/隐藏场地特效。
- `开始记录` 状态不再在启动迁移时强制关闭。

### 兼容性

- 发布包继续包含内置 `Timeline/Data`，本地开发环境不依赖构建输出复制时间轴数据。

### 稳定性

- `ActorControl` Hook 仍因启动崩溃风险保持禁用。
- 网络包增强模式默认关闭，需手动开启。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` 等已启用来源。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 进入 `军工要地克吕提俄斯魔导工厂`，确认可自动加载时间轴。
6. 打开战斗流水，选择角色并勾选“减伤分析”，确认承伤行显示 HP/减伤快照。

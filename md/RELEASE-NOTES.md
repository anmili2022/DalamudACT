# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 性能与刷新频率

- 新增“按区域自动刷新频率”，默认开启：主城/住宅使用低负载，野外使用标准，副本战斗中使用低延迟。
- 新增刷新频率预设：低负载、标准、低延迟，并提供 DPS统计、队友监控、状态监控、时间轴的独立刷新间隔滑块。
- 队友监控和状态监控改为仅战斗中刷新；非战斗时显示最后一次缓存并提示“已暂停刷新”。
- 新增强化日志开关，用于输出 `FrameworkUpdate` / `StatsUpdate` 慢帧性能日志；插件聊天通知频道固定为 Debug，移除日志频道下拉框。
- 状态监控增加缓存和限频，避免 UI 绘制时每帧读取自身/目标状态。

### 时间轴性能

- 时间轴文件解析改为后台任务，并按文件路径、修改时间、id/name 缓存解析结果，避免在 FrameworkUpdate 主线程同步读盘和解析。
- 非战斗状态仍可后台预加载时间轴，加载完成后再应用到当前区域。
- 自动刷新模式下，时间轴在主城/住宅低频维护，副本非战斗标准频率维护，副本战斗中低延迟维护。
- 同一区域、同一个保存的强制加载路径不再反复读文件头或查索引。

### 区域识别

- 新增运行时区域分类：副本、主城、野外、住宅区、特殊区域、未知。
- 设置页显示当前区域分类，用于确认自动刷新频率当前套用的区域策略。

### 界面修复

- 修复“数据与状态”中当前队伍成员表格表头文字在部分主题下不可见的问题。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` / `NpcYell` 等已启用来源。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 打开 `/dps settings` → 数据与状态，确认“按区域自动刷新频率”默认开启，当前区域分类显示正确。
6. 切换低负载、标准、低延迟预设，确认四个刷新间隔滑块同步更新。
7. 非战斗状态打开队友监控和状态监控，确认窗口显示“已暂停刷新”并保留缓存。
8. 开启强化日志，切换区域或加载时间轴，确认不再出现时间轴解析导致的长时间 `FrameworkUpdate timeline=...ms` 慢帧。

# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 战斗流水记录

- 副本内不再自动强制使用轻量战斗流水，避免承伤、减伤分析、治疗、读条、状态等勾选项没有可显示数据。
- 未开启高性能模式且未手动开启轻量战斗流水时，副本内会按完整战斗流水记录，再由窗口里的勾选项筛选显示。
- 高性能模式和手动轻量战斗流水仍保留降载行为，用于绝本、战场或高特效场景临时降低记录压力。

### 使用方式

- 想看完整流水：关闭 `高性能模式`，关闭 `轻量战斗流水`，再在战斗流水窗口勾选需要显示的类型。
- 想降低高压战斗开销：开启 `高性能模式` 或手动开启 `轻量战斗流水`。

## 已知注意事项

- 完整战斗流水会恢复伤害、治疗、读条和状态等高频记录，打开过多类型时仍可能增加高压副本中的开销。
- 如果仍需要优先保帧，请使用高性能模式或轻量战斗流水。
- 时间轴硬编码开发源路径仍只用于本地开发环境，正式发布包仍必须包含 `Timeline/Data`。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认发布包内包含 `Timeline/Data/timeline-index.json`。
4. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
5. 关闭高性能模式和轻量战斗流水后进入副本，确认战斗流水能记录承伤、减伤分析、治疗、读条和状态。
6. 只勾选部分类型时，确认窗口只显示对应类型，但记录策略不再被副本区域自动改成轻量。
7. 开启高性能模式或轻量战斗流水后，确认战斗流水回到轻量记录口径。

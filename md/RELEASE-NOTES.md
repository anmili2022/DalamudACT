# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 设置界面

- 简易设置重做为圆角控制台风格，包含顶部栏、左侧导航、中间设置页和右侧状态/快捷入口栏。
- 完整设置改为与简易设置同款三栏布局，不再使用旧式整页折叠列表堆叠。
- 简易设置和完整设置均支持主题配色切换，并在界面内显示色块预览。
- 新增 9 套 UI 主题：Sakura、Sakura Night、Ocean、Ocean Night、Forest、Purple、Sunset、Monochrome、Cyber。
- 设置窗口右下角缩放图标已隐藏，保留窗口缩放能力。
- 修复主题切换后标题栏、滚动条、下拉箭头按钮、卡片边框和导航图标没有同步换色的问题。

### UI 默认值

- 简易设置快捷入口新增“保存当前UI为默认”和“还原默认UI”。
- “还原默认UI”支持恢复用户保存的 UI 快照；未保存时回退插件默认 UI。
- UI 快照包含主题配色、窗口显隐、锁定状态、透明度、统计面板布局、时间轴/TTS 显示参数等 UI 相关设置。

### 交互细节

- 从简易设置切换到完整设置时，窗口尺寸切换为 `1044 x 600`。
- 从完整设置切回简易设置时，窗口尺寸切换为 `790 x 650`。
- 完整设置背景透明度固定为 `0.2`，不再受“主界面透明度”滑块影响。
- 主题色调色板中新增“高亮自身”开关。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` 等已启用来源。
- 部分旧设置子页仍沿用原有具体控件排列，但外层布局、主题色和主要卡片样式已统一。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 打开 `/dps settings`，确认简易设置可切换主题，标题栏、滚动条和下拉按钮同步变色。
6. 点击“完整设置”和“简易设置”，确认窗口尺寸分别切换为 `1044 x 600` 与 `790 x 650`。
7. 使用“保存当前UI为默认”和“还原默认UI”，确认主题和 UI 参数可保存/恢复。

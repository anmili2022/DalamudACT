- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 高特效战斗性能优化

- 新增高性能模式，适合绝境、战场和高特效场景。
- 高性能模式保留主要 DPS/HPS、承伤、死亡和队友技能监控，但会跳过友方 NPC 自动观察、DoT/野火归属、详细战斗流水和非队伍 ActionEffect 深解析。
- 新增轻量战斗流水模式，只记录战斗开始/结束、死亡、场地特效、头顶标记和连线，减少伤害/治疗/状态高频流水开销。
- 新增“统计 DoT/野火归属”独立开关，默认开启；关闭后降低持续/延迟伤害归属精度，但能减少高特效战斗压力。
- ActionEffect 处理新增队伍 ActorId 短缓存、目标延迟查表、来源补解析去重、技能名懒加载和调试列表按需分配。
- PvP/战场中跳过统计、技能监控、时间轴的高频战斗采集入口，降低多人技能事件导致的主线程压力。

### 稳定性与诊断

- 修复 CN 运行环境下直接访问 `IClientState.LocalPlayer` 可能触发 `MissingMethodException` 的问题。
- 强化日志开启时新增 ActionEffect 慢包日志，便于定位绝境/战场高特效阶段的具体耗时来源。

### 设置界面

- 简易设置基础页新增高性能模式、轻量战斗流水、DoT/野火归属开关。
- 完整设置的维护/性能区域新增同款性能开关和说明。
- 修复简易设置中高性能模式说明文字被裁切的问题。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `IDutyState` 在当前 CN 环境下事件订阅会导致插件构造失败，本版本不接入 `DutyWiped`。
- 高性能模式会降低 DoT、野火、友方 NPC 和完整战斗流水的精确度；精确复盘时建议关闭。
- 四个悬浮模块的后台工作跟随对应显示开关；关闭窗口会停止对应模块的大部分采集/同步工作。
- `ActorControl` 事件当前用于战斗流水采集、MapEffect 同步和团灭淡出重置；头顶标记和连线尚不触发时间轴机制同步或 TTS。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。
- 用户自放时间轴自动识别需要文件头包含 `# ZoneId: xxxx`；没有 ZoneId 的文件仍可通过强制加载测试。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 简易设置中确认可见高性能模式、轻量战斗流水、DoT/野火归属三个开关。
6. 开启高性能模式进入高特效战斗，确认主要 DPS/HPS 和队友技能监控仍正常。
7. 开启轻量战斗流水，确认死亡、头标、连线、场地特效仍记录，伤害/治疗/状态流水减少。
8. 关闭 DoT/野火归属，确认插件不报错，持续/延迟伤害归属降低符合预期。
9. 开启强化日志测试 ActionEffect 慢包日志是否限频输出。
10. 在 PvP/战场中确认插件不再因多人技能事件明显拖慢帧率。

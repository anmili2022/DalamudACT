# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### ActorControl 事件采集

- 重构 ActorControl 入口，统一处理 MapEffect、团灭淡出、头顶标记和连线事件。
- 战斗流水新增头顶标记记录，显示来源、目标和头标 ID；目标解析支持玩家和友方 NPC。
- 战斗流水新增连线和连线取消记录，显示来源、目标和连线 ID。
- 场地特效、头顶标记、连线的采集开关和内容筛选已拆分，互不影响。

### 队友监控与 TTS

- 新增队友无敌技能播报，支持神圣领域、死斗、死而不僵和超火流星。
- 新增 `播报队友无敌技能` 设置项，受总 TTS 开关控制，PvP 区域不播报，本地玩家不重复播报。
- 检测到团灭淡出时重置队友技能冷却，避免灭团后冷却显示残留。

### 窗口与默认值

- 修复时间轴悬浮窗在锁定状态下进入游戏后宽度持续增加的问题。
- 保留 Ikegami 样式默认值调整：`色块上移`、`最高伤害行上移`、`footer 上移距离` 默认均为 `3 px`。
- 保留插件列表“打开”和“设置”入口均打开设置窗口的修复。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 事件当前用于战斗流水采集、MapEffect 同步和团灭淡出重置；头顶标记和连线尚不触发时间轴机制同步或 TTS。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。
- 用户自放时间轴自动识别需要文件头包含 `# ZoneId: xxxx`；没有 ZoneId 的文件仍可通过强制加载测试。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 打开战斗流水，分别开启“显示场地特效”“显示头顶标记”“显示连线”，确认三类记录和筛选互不影响。
6. 在含头标/连线机制中确认头顶标记显示来源、目标和头标 ID，连线显示来源、目标和连线 ID。
7. 打开时间轴悬浮窗，未锁定时确认可以自由拉大拉小。
8. 锁定时间轴悬浮窗，确认进入游戏或切换区域后窗口不会持续变宽。
9. 开启 TTS 总开关和“播报队友无敌技能”，确认队友无敌技能会播报，本地玩家和 PvP 区域不重复播报。
10. 在插件列表中点击“打开”和“设置”，确认两者都打开同一个设置窗口。

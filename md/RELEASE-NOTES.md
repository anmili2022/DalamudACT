# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 队友监控

- 新增队友监控悬浮窗，可监控食物、减伤技能和团辅技能。
- 支持匿名模式、本地玩家兜底显示、按职业勾选技能和添加自定义技能。
- 支持 CD 中技能隐藏开关和团辅 / 减伤合并显示开关。
- 食物监控识别 `StatusId = 48` 的 `进食` 状态。

### UI 与设置

- 队友监控新增样式卡片，可调整图标大小、倒计时数字大小、背景颜色和起效增强强度。
- 名字 / 职业标签使用职业占比条配色作为背景，白色文字提高可读性。
- 起效中技能使用金色高亮边框，减伤起效额外显示 `效` 标记。
- `按职业选择监控技能` 设置区支持折叠。

### 战斗统计

- 修复纯治疗事件独立开启假战斗的问题，避免刚进本或战斗结束后的妖精治疗生成 1 秒战斗。
- 修正机工士 `武装解除` 冷却时间为 120 秒。

### 稳定性

- `ActorControl` Hook 仍因启动崩溃风险保持禁用。
- 本地玩家读取优先使用 `ObjectTable.LocalPlayer`，避免直接强类型调用已移除的 `IClientState.LocalPlayer`。
- 设置页新增 `打印当前BUFF` 调试按钮，便于排查状态 ID、分类和剩余时间。

## 已知注意事项

- DoT / HoT / Wildfire 等持续效果仍建议结合 `tools/DotReconcile` 与 ACT 日志继续做真实场景对账。
- 如果食物监控异常，优先点击 `设置 -> 数据与状态 -> 打印当前BUFF` 查看实际状态数据。
- 不要手动恢复 `ActorControl` Hook；如需恢复，必须先做地址范围校验、页保护校验和显式配置开关。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 进入普通队伍、跨服队伍或无队伍状态，确认队友监控至少能显示本地玩家。
6. 使用食物和减伤技能，确认食物状态、起效金边、CD 隐藏 / 倒计时显示正常。

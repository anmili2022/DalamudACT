# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 模块硬开关

- 统计面板、技能监控、时间轴、状态监控现在都与各自悬浮窗显示绑定为硬开关。
- 关闭统计面板后不再运行统计刷新，也不再写统计类战斗流水。
- 关闭技能监控后不再刷新队友技能窗口、不再记录队友技能冷却、不再触发无敌技能 TTS 或倒计时重置。
- 关闭时间轴后不再运行时间轴更新，也不再处理技能、系统日志、台词、MapEffect 等时间轴同步入口。
- 状态监控继续保持窗口关闭即不刷新状态列表。

### 组合使用

- 支持只开启技能监控：统计面板、时间轴、状态监控关闭时，技能监控仍会通过轻量 ActionEffect 路径记录队友技能冷却。
- 支持只开启时间轴：统计面板和技能监控关闭时，时间轴仍可独立处理自己的同步来源。

### 继续保留

- 保留 `0.15.2.64` 的加载稳定性修复、战斗倒计时两句确认重置和团灭结算兜底。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `IDutyState` 在当前 CN 环境下事件订阅会导致插件构造失败，本版本不接入 `DutyWiped`。
- 四个悬浮模块的后台工作现在跟随对应显示开关；关闭窗口会停止对应模块的大部分采集/同步工作。
- `ActorControl` 事件当前用于战斗流水采集、MapEffect 同步和团灭淡出重置；头顶标记和连线尚不触发时间轴机制同步或 TTS。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。
- 用户自放时间轴自动识别需要文件头包含 `# ZoneId: xxxx`；没有 ZoneId 的文件仍可通过强制加载测试。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 只开启统计面板，确认 DPS/HPS/承伤正常刷新，技能监控、时间轴、状态监控不工作。
6. 只开启技能监控，确认队友技能冷却正常记录，统计面板、时间轴、状态监控不工作。
7. 只开启时间轴，确认时间轴同步正常，统计面板、技能监控、状态监控不工作。
8. 只开启状态监控，确认状态列表正常刷新，统计面板、技能监控、时间轴不工作。
9. 全部开启，确认四个模块都正常工作且互不影响。
10. 开启技能监控后测试战斗倒计时两句确认重置；关闭技能监控后确认倒计时不会重置技能冷却。

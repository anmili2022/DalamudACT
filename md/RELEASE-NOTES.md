# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 时间轴修复

- 修复在线时间轴下载后无法被自动识别的问题：加载路径现在正确读取 `Timeline/RemoteCache/Data`。
- 在线刷新当前副本、更新时间轴和自动下载后会刷新索引缓存并重新加载当前区域时间轴。
- 用户把 `.txt` / `.cn.txt` 放到配置目录 `Timeline/Data` 后，只要文件头包含 `# ZoneId: xxxx`，即使没有 `timeline-index.json` 也可按区域自动识别。
- 规范神龙幻巧时间轴同步点，避免阶段 3 读条同步回跳到阶段 2。

### 界面与设置

- “高亮自身”改为只在本地玩家名字或极简/池上显示文本前加 `★`，不再改变占比条颜色。
- 移除高亮自身下方的颜色单选项，并更新说明文案。
- “窗口与悬浮面板”设置拆分为 DPS统计、队友监控、状态监控、时间轴四个板块。
- 移除主界面透明度设置项，保留各悬浮窗透明度设置。
- 新增自身高亮星标 HTML 预览页，方便比较显示效果。

### 战斗流水

- “开始记录”默认开启，并说明开关状态会保存到配置。
- “保留与筛选”里的自动滚动、角色筛选、全文搜索、内容类型筛选会保存，下次打开继续沿用。

### 上版重点

- 保留 `0.15.2.58` 的时间轴注释过滤、读条/结算应对方案播报修复、克吕提俄斯第一 Boss 同步修复和时间轴撰写指南。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` / `NpcYell` 等已启用来源。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。
- 用户自放时间轴自动识别需要文件头包含 `# ZoneId: xxxx`；没有 ZoneId 的文件仍可通过强制加载测试。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 使用“刷新当前副本时间轴”或“更新时间轴”下载在线时间轴，确认当前区域可自动加载远程缓存文件。
6. 把带 `# ZoneId: xxxx` 的时间轴放到配置目录 `Timeline/Data`，确认不写索引也能自动匹配。
7. 在极简和池上样式中开启“高亮自身”，确认自身前显示 `★` 且占比条颜色不变。
8. 打开战斗流水，确认“开始记录”和“保留与筛选”选项重开窗口后仍保留。

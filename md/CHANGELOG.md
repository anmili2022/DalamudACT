## 0.15.2.67 - 2026-06-10

### 简易设置

- 简易设置新增独立“性能”页签，集中显示高性能模式、轻量战斗流水和 DoT/野火归属开关，避免基础页无滚动时控件被裁切。

### 队友监控

- 非战斗暂停刷新时，已缓存技能冷却和起效时间继续动态倒计时，黄色起效框会自然显示到持续时间结束。
- 技能监控的暂停标记统一放到 `技能监控 (数量)` 标题行右侧，与状态监控标题行暂停标记保持一致。
- 从副本返回非副本区域时，技能监控会自动刷新一次缓存，随后继续保持非战斗低负载暂停策略。

### 状态监控

- 状态监控暂停提示改为标题行右侧小徽标，鼠标悬停时显示完整说明，减少非战斗时的文本占位。

## 0.15.2.66 - 2026-06-09

### 性能优化

- 新增高性能模式，面向绝境、战场和高特效场景，保留主要 DPS/HPS、承伤、死亡和队友技能监控，同时跳过高开销的友方 NPC 自动观察、DoT/野火归属、详细战斗流水和非队伍 ActionEffect 深解析。
- 新增轻量战斗流水模式，只保留战斗开始/结束、死亡、场地特效、头顶标记和连线，减少伤害/治疗/状态等高频流水带来的字符串构造和 UI 历史压力。
- 新增“统计 DoT/野火归属”独立开关，默认开启；关闭后不再记录 DoT 候选、野火采样或运行 DoT/野火轮询模拟。
- ActionEffect 热路径增加队伍 ActorId 短缓存，减少高频技能事件中对 PartyList/ObjectTable 的重复扫描。
- ActionEffect 目标解析改为延迟查表，只有治疗目标或需要纳入友方 NPC 时才反查 ObjectTable。
- 同一个 ActionEffect 包内友方来源补解析最多尝试一次，避免 Boss 多段 AoE 对每个目标重复解析来源。
- 未开启伤害统计 debug 时不再为每个技能包分配调试目标列表，技能名也改为需要写统计/流水/日志时再懒加载。
- 强化日志开启时新增 ActionEffect 慢包日志，用于定位高特效战斗中的单包处理耗时。

### 稳定性

- 修复 CN 运行环境下直接访问 `IClientState.LocalPlayer` 可能触发 `MissingMethodException` 的问题，改用项目内兼容的本地玩家身份解析入口。
- PvP/战场中跳过统计、技能监控、时间轴的高频战斗采集入口，避免多人技能事件导致主线程压力过高。

### 设置界面

- 简易设置基础页新增高性能模式、轻量战斗流水、DoT/野火归属开关，并修复高性能模式说明文字被裁切的问题。
- 完整设置的维护/性能区域新增同款性能开关和说明。

## 0.15.2.36 - 2026-05-25

### 队友监控

- 新增队友监控悬浮窗，支持食物、减伤和团辅技能监控。
- 支持匿名模式，悬浮窗可用职业名代替玩家名。
- 支持本地玩家兜底显示，跨服队伍或无队伍时也能显示自身监控。
- 支持按职业勾选技能和添加自定义技能。
- 支持 CD 中技能隐藏开关，默认隐藏长 CD 图标并在剩余 10 秒内重新显示。
- 支持团辅 / 减伤合并显示开关，默认分组显示。

### 队友监控样式

- 增加队友监控样式卡片，可调整图标大小、倒计时数字大小、背景颜色和起效增强强度。
- 起效中的技能使用金色高亮边框，减伤起效额外显示 `效` 标记。
- 名字 / 职业标签使用职业占比条配色作为背景，白色文字提升可读性。
- 修复技能全部进入长 CD 后下一行图标上移占位的问题。

### 战斗统计

- 修复纯治疗事件独立开启假战斗的问题，避免刚进本或战斗结束后的妖精治疗生成 1 秒战斗。
- 修正机工士 `武装解除` 冷却时间为 120 秒。

### 兼容与调试

- 食物监控明确识别 `StatusId = 48` 的 `进食` 状态，并兼容当前 Dalamud 状态类型差异。
- 设置页新增 `打印当前BUFF` 调试按钮，用于排查状态 ID、分类、剩余时间等字段。
- 新增队友监控交接文档 `md/2026-05-25-party-monitor-handoff.md`。

### 文档与维护

- 新增 `md/ENCODING-GUIDE.md`，记录 UTF-8 写作规范和 Windows PowerShell 下的安全读写方式。
- 新增 `tools/Check-TextEncoding.ps1`，用于检查当前 Git 变更 / 未跟踪文本文件是否存在无效 UTF-8 或疑似 mojibake。
- 新增 `.editorconfig`，统一文本文件使用 UTF-8、LF 换行和文件末尾换行。
- 整理 `HANDOVER.md`、`md/SESSION-HANDOFF.md`、`md/2026-05-24-npc-party-handoff.md` 为可读交接入口。
- 更新维护入口文档：

## 0.15.2.34 - 2026-05-24

### NPC 队友识别

- 接入并整理 NPC 队友识别链路：
  - 本地玩家；
  - `PronounModule <1>~<8>`；
  - `AgentHUD.PartyMembers`；
  - Dalamud `PartyList`；
  - `BuddyList`；
  - `ObjectTable` 中可识别的友方 NPC。
- 增加 / 整理友方 NPC 名单逻辑：内置 NPC 名单、自定义 NPC 名单、名字规范化、当前队伍成员展示。
- `OwnerId` 不再一律等同宠物归属；只有明确的 `Pet / Buddy / RaceChocobo` 走 owner 归属，信赖 / 剧情 NPC 队友应独立统计。
- 不再单靠 `StatusFlags.Hostile` 判断 NPC 队友，避免信赖 / 幻体 / 任务 NPC 被误判。

### UI 与显示

- 设置页新增 / 整理 `NPC 队友识别名单`，用于核对玩家和 NPC 队友是否进入统计。
- 悬浮统计增加对象显示口径：
  - 智能：多人仅玩家，单人可含友方 NPC；
  - 玩家 + 友方 NPC；
  - 玩家 + 敌方 NPC。
- 统计 payload 中保留 `participantKind`：
  - `player`
  - `friendlyNpc`
  - `hostileNpc`
- NPC 行支持高亮和专用 badge：友方 NPC 显示 `友`，敌方 NPC 显示 `敌`。

### Debug 战斗记录

- 战斗流水和 debug 战斗记录默认关闭，避免普通使用时产生过多记录。
- debug 战斗记录 UI 继续使用 `Boss / 小怪` 与 `友方` 两组。
- 友方记录项支持：标记、技能、BUFF、debuff。

### 稳定性

- `ActorControl` Hook 仍因启动崩溃风险默认禁用。
- 避免使用 `PronounModule.ResolvePlaceholder(string, byte, byte)`，改走 `MemberFunctionPointers.ResolvePlaceholder(...)`，避免运行时 `MissingMethodException`。
- 修正部分攻击技能附带 `Heal` 效果时被错误写成“治疗 Boss”的口径，当前 HPS 只统计目标是已追踪友方对象的治疗。

## 0.15.2.9 - 2026-05-12

### DoT 统计

- 玩家 DoT 主链路切换为“状态驱动 + 3 秒轮询补 tick”，不再依赖事件包里的 DoT tick 直接记账。

# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 食物监控

- 食物分组现在显示未进食和剩余时间不足提醒阈值的成员，并将标题明确为 `需补食`。
- 未进食成员使用红色边框，即将到期成员使用橙黄色边框，保留职业底色方便识别。
- 鼠标悬停成员标签时显示食物剩余时间；未进食成员会显示未检测到食物效果。
- 新增 `食物到期提醒阈值` 设置，默认 10 分钟，可在 1 至 60 分钟之间调整。
- 食物状态在战斗外每秒低频刷新，进本准备、倒计时和补食后可以及时更新；技能监控仍保持战斗外暂停。
- 锁定队友监控窗口后仍可查看 Tooltip，同时继续禁止窗口移动、缩放和右键打开设置。

### 设计与维护

- 更新队友监控设计文档，补充异常筛选、边框语义、Tooltip、配置持久化和战斗外刷新策略。

## 已知注意事项

- 食物状态读取失败时目前仍无法与未进食可靠区分，会按未检测到食物效果显示。
- 时间轴硬编码开发源路径仍只用于本地开发环境，正式发布包仍必须包含 `Timeline/Data`。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认发布包内包含 `Timeline/Data/timeline-index.json`。
4. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
5. 把食物提醒阈值调到高于当前剩余时间，确认成员进入 `需补食` 分组并显示橙黄色边框。
6. 悬停即将到期成员，确认 Tooltip 显示剩余时间和提醒阈值。
7. 战斗外补食后等待约一秒，确认成员状态自动更新。
8. 锁定队友监控窗口后，确认窗口不可移动但 Tooltip 仍可显示。

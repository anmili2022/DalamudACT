# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 队友与状态监控

- 修复双暗骑场景中，一个暗骑释放至黑之夜或献奉时，另一个暗骑也显示进入冷却的问题。
- 技能监控和状态监控在非战斗暂停时，点击标题右侧的 `暂停` 徽标会立即刷新一次缓存。

### DPS 悬浮窗

- 极简模式总 DPS 栏新增悬停提示，显示 `[战斗时间-总DPS]`。
- 队友 DPS tooltip 新增死亡次数显示。

### 时间轴 TTS

- 副本内保留轻量的 `结算ID` 和 `读条ID` 应对方案 TTS 触发，不恢复重型自动同步和跳轴。
- `读条ID` 应对方案只在当前时间轴存在读条应对配置时低频扫描，并且只处理白名单 actionId，降低卡顿风险。

### 构建维护

- 发布流程文档补充本机构建无法解析 Dalamud 引用时的 `DalamudLibPath` 兜底构建命令。

## 已知注意事项

- 读条ID应对方案仍需要低频扫描敌方读条；高性能模式会关闭这条轻量扫描路径。
- 如果仍需要优先保帧，请使用高性能模式。
- 时间轴硬编码开发源路径仍只用于本地开发环境，正式发布包仍必须包含 `Timeline/Data`。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认发布包内包含 `Timeline/Data/timeline-index.json`。
4. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
5. 双暗骑进本后分别释放至黑之夜或献奉，确认只有施放者进入冷却。
6. 非战斗时点击技能监控和状态监控的 `暂停` 徽标，确认缓存会立即刷新。
7. 极简模式悬停总 DPS，确认显示 `[战斗时间-总DPS]`。
8. 配置了读条ID或结算ID应对方案的时间轴中，确认应对方案 TTS 能播报。

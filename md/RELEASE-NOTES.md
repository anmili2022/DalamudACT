# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 时间轴同步

- 强制加载时间轴路径会保存到配置，并在副本内重载插件时按文件头 `# ZoneId` 自动恢复。
- 强制加载时间轴后改为等待真实同步，不再点击加载后直接从 0 秒开始运行。
- 新增 `InCombat` 同步支持，进入战斗时可启动包含 `InCombat` 条目的时间轴。
- `InCombat` 启动补偿调整为 `0.3s`，并增加短暂脱战宽限，减少进战瞬间倒计时条闪烁。
- 新增 Boss 台词 / `NpcYell` 同步支持，复用聊天消息来源触发时间轴同步。

### 回顾与战斗流水

- 新增回顾模式：开启后 Duty Recorder 回放按真实战斗进入统计、战斗流水和时间轴；关闭时只喂时间轴。
- 回顾模式支持空闲脱战判定，避免回放结束后统计和时间轴长期不重置。
- 战斗流水新增战斗内相对时间显示，并提供“战斗时间 / 原始时间”开关。

### 时间轴显示与提示

- 时间轴 Debug 模式底部新增当前运行源文件行号，例如 `[20.35]当前运行第2行`。
- 当前时间轴文件按钮统一为只显示文件名：左键打开所在文件夹，右键复制完整路径。
- 时间轴机制提示只使用文件中显式 `#` 注释，不再运行时套用 cactbot 机制映射，减少误提示。
- 默认 TTS 纠偏新增 `三重猛击 -> 三虫猛击`。

### 性能优化

- 合并并限频 ObjectTable / BattleChara 扫描，时间轴读条和战斗流水读条共用快照。
- 统计、时间轴维护、RawPacket 状态检查、队友监控和状态监控改为错峰或按需执行。
- DoT / 野火统计改为分批扫描、分批模拟和分批清理，降低大规模战斗中的主线程压力。
- 慢帧性能日志默认关闭，避免影响普通 DEBUG 用途。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` / `NpcYell` 等已启用来源。
- 强制加载时间轴需要等待同步事件；如果时间轴文件缺少可用同步点，倒计时不会自动开跑。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 强制加载带 `# ZoneId` 文件后重载插件，确认匹配当前区域时会自动恢复加载。
6. 进入战斗确认包含 `InCombat` 条目的时间轴能启动，且倒计时条不反复闪烁。
7. 开启回顾模式播放 Duty Recorder，确认统计、战斗流水和时间轴按回顾事件推进。
8. 打开时间轴 Debug 模式，确认底部显示当前运行行号。

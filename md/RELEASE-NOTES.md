# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 非副本低负载策略

- 野外与特殊区域现在使用和主城、住宅区一致的低负载刷新策略，降低大型开放地图、特殊地图和非副本区域中的默认后台压力。
- 时间轴模块现在只在副本区域启用；野外、主城、住宅区和特殊区域不会加载、显示或同步时间轴。
- 离开副本后会主动禁用并清理当前时间轴状态、缓存、TTS 去重和同步观测状态，避免旧副本时间轴残留到非副本区域。
- 针对用户反馈的 1319「奥克塞西亚行星」一类非副本区域，插件会按野外低负载处理，而不是继续执行时间轴同步工作。

### 界面性能减负

- 时间轴悬浮窗增加行数据短缓存，减少窗口打开时每帧文本测量、机制名截断、排序和列表分配。
- DPS 面板增加战斗快照级排序/汇总缓存，减少每帧 LINQ 排序、总量统计和数字文本解析。
- 仅打开 DPS 统计和时间轴两个窗口时，非副本区域应进入接近主城/住宅区的低负载状态。

### 副本内保护保持不变

- 保留 0.15.2.68 的副本内高频 Ability / StartsUsing 重同步保护，避免绝本或高压副本中的主线程卡顿回归。
- 副本内仍可正常使用时间轴；本次改动只限制非副本区域的时间轴加载、显示和同步入口。

## 已知注意事项

- 时间轴设计目标调整为只服务副本区域；如果在野外、主城、住宅区或特殊区域看到时间轴窗口消失，属于本版本预期行为。
- 如果某个实际副本被区域分类误判为非副本，请记录 TerritoryId、区域名和内容类型，后续需要补充区域判定规则。
- 如果仍能在非副本区域复现明显掉帧，请优先确认是否同时打开了状态监控、队友技能监控、完整战斗流水或强化日志。
- 高性能模式、轻量战斗流水和 DoT/野火归属开关仍保留，可在高压场景中作为额外降载手段。
- 时间轴硬编码开发源路径仍只用于本地开发环境，正式发布包仍必须包含 `Timeline/Data`。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认发布包内包含 `Timeline/Data/timeline-index.json`。
4. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
5. 在主城和住宅区打开 DPS 统计与时间轴窗口，确认维持低负载状态且时间轴不显示、不同步。
6. 在 TerritoryId 1319 或同类野外/特殊区域打开 DPS 统计与时间轴窗口，确认按低负载运行且时间轴状态显示为非副本禁用。
7. 进入副本后确认时间轴可正常加载、窗口可显示，DPS / HPS / 承伤基础统计仍能刷新。
8. 离开副本返回野外或主城后，确认时间轴会被清理并停止同步，不残留上一场副本的机制提示。
9. 对比 0.15.2.68 之前的场景，确认只开 DPS 统计和时间轴两个窗口时帧率不再在非副本区域反复抖动。

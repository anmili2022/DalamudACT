# 交接记录 2026-06-01

## 本轮完成内容

### 1. 简易设置界面
- 新增 `SettingsWindow.QuickSettings.cs` — 替代原有14个partial文件的复杂设置页
- 默认打开简易模式，右上角「完整设置 →」可切换到原详细界面
- 包含：窗口显隐/锁定、透明度、悬浮样式、TTS播报、时间轴参数
- 完整设置页左上角「← 简易设置」可切回

### 2. 自动下载时间轴
- 新增配置项 `TimelineAutoDownloadOnEnter`（默认关闭）
- 进入副本时自动检测：下载远程索引 → 匹配当前zone → 按需下载缓存
- 冷却机制：全局5分钟检查冷却 + 每zone 1小时下载冷却
- DEBUG区显示自动下载状态（已下载/已更新/已是最新/无在线时间轴/下载失败）
- `TimelineRemoteResourceDownloader.AutoDownloadForZoneAsync()` 新增方法

### 3. 修复 读条ID 注解丢失问题
- `AppendTriggerHints` 对单ID行只输出 `# hint`，丢失 `读条ID XXX` 前缀
- 修复：所有匹配的 StartsUsing 触发器 ID 一律输出 `# 读条ID XXX hint`
- 删除不再调用的 `NormalizeCombinedHints`
- 重新生成 44 个 `.cn.txt` 文件（24 raid + 12 trial + 6 dungeon + 2 alliance）
- 因 bundle 无数据保持原样：klythios(1345)、necron-normal(1295)

### 4. 提取工具增强
- `ParseChineseReplacements` 正则升级为 `(?:[^'""`\\]|\\.)+`，支持 JS 转义引号
- 新增 `UnescapeJsString` 处理 `\'`、`\"`、`\\`
- `KnownZoneNames` 补齐所有24个raid zoneId映射
- `FindTimelineFileNameForZone` 新增 `CONCATENATED MODULE` 注释 fallback

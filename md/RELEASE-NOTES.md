# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 简易设置性能页

- 简易设置新增独立“性能”页签。
- 高性能模式、轻量战斗流水、统计 DoT/野火归属三个开关集中放到性能页，避免基础页无滚动时控件被裁切。

### 队友监控体验

- 非战斗暂停刷新时，已缓存技能冷却仍会继续倒计时。
- 技能起效黄色框会按剩余持续时间自然显示到结束，不再因为暂停刷新而冻结。
- 从副本返回非副本区域时，技能监控会自动刷新一次缓存，随后继续保持非战斗低负载暂停策略。
- 技能监控暂停标记统一放到 `技能监控 (数量)` 标题行右侧，与状态监控暂停标记位置一致。

### 状态监控体验

- 状态监控暂停提示改为标题行右侧小徽标。
- 鼠标悬停暂停徽标时显示完整说明，减少非战斗时的文本占位。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `IDutyState` 在当前 CN 环境下事件订阅会导致插件构造失败，本版本不接入 `DutyWiped`。
- 高性能模式会降低 DoT、野火、友方 NPC 和完整战斗流水的精确度；精确复盘时建议关闭。
- 四个悬浮模块的后台工作跟随对应显示开关；关闭窗口会停止对应模块的大部分采集/同步工作。
- `ActorControl` 事件当前用于战斗流水采集、MapEffect 同步和团灭淡出重置；头顶标记和连线尚不触发时间轴机制同步或 TTS。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。
- 用户自放时间轴自动识别需要文件头包含 `# ZoneId: xxxx`；没有 ZoneId 的文件仍可通过强制加载测试。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 简易设置中确认左侧存在“性能”页签，且三项性能开关可见。
6. 非战斗暂停刷新时确认技能监控冷却数字继续倒计时，黄色起效框会自然结束。
7. 确认技能监控和状态监控的 `暂停` 徽标都位于标题行右侧。
8. 从副本返回大地图或主城后，确认技能监控会刷新一次缓存。
9. 鼠标悬停暂停徽标，确认显示完整暂停说明。
10. 回归确认高性能模式、轻量战斗流水、DoT/野火归属三个开关仍能保存并立即生效。

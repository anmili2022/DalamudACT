# DalamudACT {{VERSION}} 发布说明

- 目标版本：`{{VERSION}}`
- 本文件由 `.github/workflows/release.yml` 读取并写入 GitHub Release 正文。
- 发布前请确认 `{{VERSION}}` 已与 tag、项目版本和仓库 metadata 保持一致。

## 本次重点

### 时间轴修复

- 修复 `#Ability { ... }` / `#StartsUsing { ... }` 这类行尾事件参考被当成机制提示显示到倒计时条的问题。
- 修复 `读条ID` / `结算ID` 应对方案即时播报绕过“播报技能名”开关的问题；未勾选技能名时只播应对方案文本。
- 修复军工要地克吕提俄斯魔导工厂第一 Boss 时间轴被路上小怪战斗提前触发的问题，第一 Boss 改用封锁系统日志同步。

### 文档

- 新增 HTML 时间轴撰写指南，说明基础语法、同步事件、机制提示、`读条ID` / `结算ID` 应对方案和验证流程。
- 指南补充 `duration` 持续条写法，例如 `3101.5 "跃动的大地 (弧线)" duration 3.7`。

### 界面修复

- 高亮自身的“白底黑字”样式调整为白底黄字，提高可读性。

### 上版重点

- 保留 `0.15.2.57` 的性能优化：按区域自动刷新频率、时间轴后台解析缓存、队友/状态监控非战斗暂停刷新、强化日志。

## 已知注意事项

- 时间轴硬编码源码路径仅用于当前本地开发环境，不应随意修改。
- `ActorControl` 时间轴行仍不会触发同步；当前只依赖 `Ability` / `SystemLogMessage` / `NpcYell` 等已启用来源。
- 队友监控和状态监控默认非战斗暂停刷新，窗口会显示最后一次缓存。
- 区域分类中的主城/住宅区使用内置 TerritoryId 表；如有遗漏区域，后续会继续补充。
- `duration` 当前用于时间轴数据字段和持续条语义说明；倒计时窗口是否完整展示持续过程以后续实现为准。

## 验证建议

1. 确认 GitHub Release 页面标题为 `DalamudACT {{VERSION}}`。
2. 确认 Release 资产中包含 `DalamudACT.zip`。
3. 确认仓库 metadata / pluginmaster 中的下载链接指向本次 tag。
4. 在游戏中加载插件，确认主窗口显示版本与 `{{VERSION}}` 一致。
5. 加载包含 `#Ability { ... }` 行尾参考的时间轴，确认倒计时条不显示该参考文本。
6. 关闭“播报技能名”后触发 `读条ID` / `结算ID` 应对方案，确认只播应对方案。
7. 进入军工要地克吕提俄斯魔导工厂，确认路上小怪战斗不会提前显示第一 Boss 时间轴。
8. 打开 HTML 时间轴撰写指南，确认 `duration` 示例和应对方案说明可读。
